# Отчет по лабораторной работе №4

## Ответы на контрольные вопросы

1. **Чем опасен world-writable каталог?**
   Любой пользователь может создавать, удалять или переименовывать файлы в нем. Это вектор атак: злоумышленник может подменить скрипт, который будет запущен от имени `root`, и повысить привилегии.

2. **Почему проверка `-e` не всегда достаточна?**
   Флаг `-e` проверяет только факт существования. Он не проверяет права доступа, не различает типы (файл, каталог, ссылка) и не гарантирует, что файл не будет удален сразу же после проверки (TOCTOU).

3. **В чем отличие символьной и жесткой ссылки?**
   Жесткая ссылка — это дополнительное имя для того же inode. Она не может пересекать границы файловых систем. Символическая ссылка — это файл, содержащий текстовый путь к другому файлу. Она может указывать на несуществующие пути или другие ФС.

4. **Что такое TOCTOU и почему Bash плохо подходит для атомарной проверки?**
   TOCTOU (Time-of-check to time-of-use) — уязвимость из-за задержки между проверкой и действием. В Bash нет системных вызовов вроде `openat` с флагом `O_EXCL`. Любая последовательность команд Bash — это отдельные процессы, между которыми файловая система может измениться.
